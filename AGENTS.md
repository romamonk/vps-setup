# Инструкции для работы с репозиторием

- Источник требований: `VPS_CLAUDE_CODE_BOOTSTRAP_SPEC.md`.
- Текущий этап — каркас; не описывать запланированные роли как реализованные.
- Основной инструмент настройки — Ansible. Параметры хоста передавать через inventory.
- Не выполнять реальные изменения на VPS без явного указания владельца.
- Не добавлять в Git реальные адреса, private keys, пароли и токены.
- Пользователь `agent` не должен получать sudo или доступ к rootful Docker daemon.
- Проверка административного входа по ключу должна предшествовать отключению
  root/password login и включению firewall. Проверять конфигурацию SSH до reload.
- Не включать `--dangerously-skip-permissions` или автозапуск Claude по умолчанию.
- Перед реализацией установки инструментов проверять актуальную официальную документацию.
- Добавлять зависимости только по мере использования; не создавать фиктивные роли
  и проверки, выдающие незавершённую настройку за успешную.
- Документацию вести на русском; YAML оформлять с отступом в два пробела.
