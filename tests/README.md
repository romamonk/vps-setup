# План проверок

Автоматические проверки пока не реализованы. По мере добавления ролей нужны:

- YAML/Ansible lint и syntax checks playbooks.
- Проверка обязательных параметров inventory до изменений на хосте.
- Проверка `sshd -t`, эффективной конфигурации и входа по ключу.
- Проверка отсутствия sudo и доступа к системному Docker у `agent`.
- Проверка firewall и доступности опубликованных портов с внешнего хоста.
- Проверка настроек автоматических обновлений и работы tmux.
- Повторный прогон на тестовой VM для проверки идемпотентности.

Проверки на реальном VPS требуют явного указания владельца.
