# Проверки

`make lint syntax` проверяет YAML, Ansible lint и синтаксис всех playbooks.
CI запускает те же проверки без доступа к реальному серверу.

`playbooks/verify.yml` проверяет состояние настроенного VPS. После применения
повторить playbooks через admin: ожидается `changed=0`, кроме фактических
обновлений состояния. Отдельно проверить внешний доступ к портам и tmux
через два SSH-соединения. Реальный VPS используется только с разрешения владельца.

Первичный парольный bootstrap и аварийное восстановление требуют отдельной
тестовой VM; проверка синтаксиса не подтверждает эти сценарии.

## Проверка на реальном VPS, 2026-11-03

- Ubuntu 24.04.5 LTS x86_64, после обновления и reboot — ядро 6.8.0-147-generic.
- Проверены независимые ключевые входы admin/agent, sudo администратора и
  отсутствие sudo/доступа к Docker socket у agent.
- Новый root SSH-вход отклонён; UFW разрешает только TCP/22 для IPv4 и IPv6.
- Внешняя IPv4-проверка: TCP/22 доступен; 80, 443, 2375, 2376, 3000, 5432,
  6379, 8000, 8080, 8443 закрыты либо фильтруются. Это не полный скан портов.
- Claude Code 2.1.309 запускается под agent; пользовательская авторизация
  не выполнялась и остаётся интерактивным шагом владельца.
- Проверены attach/detach tmux и сохранение сессии через новое SSH-соединение.
- Lint и syntax checks прошли; проверки состояния выполняются после reboot.
- Повторные bootstrap, configure и harden через admin завершились с `changed=0`.

На этом VPS исходный доступ был по ключу. Парольный bootstrap, аварийный
откат SSH и внешний IPv6-доступ в этом прогоне не проверялись.
